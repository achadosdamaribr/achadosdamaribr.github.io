Política de Privacidade — Achado Lar

Última atualização: 19 de novembro de 2026

O Achado Lar (perfil @meu.achadolar no Instagram e @meuachadoslar no Pinterest) é um projeto de curadoria de produtos para casa da Curadorias da Mari. Esta política explica como tratamos dados.

1. Dados que coletamos

Não coletamos dados pessoais de visitantes. Este site não tem cadastro, formulários, loja própria nem cookies próprios.

2. Uso da API do Pinterest

O aplicativo "Achado Lar Publicador" usa a API do Pinterest apenas para criar e agendar Pins e organizar pastas na nossa própria conta. Ele não acessa, armazena ou compartilha dados de outros usuários do Pinterest. Os tokens de acesso ficam guardados de forma privada e são usados só para publicar na nossa conta.

3. Links de afiliado

Alguns links levam a lojas parceiras, como Shopee, Mercado Livre, Magalu e Amazon, e podem gerar uma comissão para nós, sem custo extra para quem compra. A compra, a entrega, as trocas e o tratamento dos dados do comprador são de responsabilidade da loja, conforme a política de privacidade de cada uma.
